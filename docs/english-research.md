## 方法与范围

使用 REA `capture_browser_scenario`，指定本机 Chrome `155.0.8059.40`，每次由 REA 启动独立临时浏览器配置并在结束后关闭。默认视口 1280×720，英文区域设置、UTC 时区、浅色、减少动态效果、无预置登录状态。场景执行按钮点击、输入及按键，保留逐步 accessibility 状态，必要时读取 DOM 确认选择器。没有采集网络响应正文、用户凭据或用户浏览器配置。

场景契约见 [REA 官方说明](https://github.com/morluto/rea/blob/main/docs/browser-scenario-contract.md)。本报告只把实际场景状态列为观察；未执行的网站内部代码、持久化实现、数据库、算法与计费规则均不作事实结论。

## Sariana 自主设计与实现要求

以下行为来自本次产品计划，不应标注为外站原有功能：

- 使用“大”字号为默认并保持原有纸张、配色和 PySide6 Widgets 风格，三档字号通过本机设置保存。
- 首次作答与复测成绩分开保存；答错、提示或看答案进入纠正，纠正不记成绩，可跳过。原轮结束后每个相关词只做一次隐藏答案复测，不无限循环。
- 轮末分别展示首次独立正确率、纠正情况与复测结果，成功保存之前不推进或庆祝；稳定操作 ID 用于重试。
- 复习以凌晨 4 点应用日计算，间隔为 1／3／7／14／30 天，每词每天最多晋级一次；失败或辅助完成重置排期。
- 语句反馈沿用本机词级评分和对齐结果，显示错词、漏词、多词；同句重练直接复用本机材料，不重新生成或扣券。

外站观察给出的方向是“明确练习状态、及时核对、保留首次困难、可控重复、隐藏答案”。Sariana 使用 Presenter 持有会话、只读展示模型和 ApplicationWorker 异步保存，在 english 模块的公开 API 实现纯规则，不引入网页前端或外站服务依赖。
