# 打字管家（TypingTracker）

<div align="center">

**本地单机桌面打字统计应用** · Python + PySide6 + pyqtgraph · 纯本地，无联网

后台全局统计你的打字，用"每日打卡 / 等级 / 成就 / 挑战"陪你坚持练习 ✨

</div>

## ✨ 功能总览

| 模块 | 说明 |
|------|------|
| 🖥️ 后台统计 | Windows 全局键盘钩子，关窗驻留托盘继续统计 |
| 🀄 IME 精确计数 | 中文按**上屏字符**计（汉字=2tw、字母=1tw），组字退格不计删除；TSF 输入法精确到上屏汉字 |
| 📊 今日概览 | 有效字数 / 平均速度 / 正确率大数字卡 + 逐分钟曲线 |
| 📈 可视化报表 | 趋势分析（7/30/90 天三视角）、年度热力图、24 小时时段分布、周月报对比 |
| 📅 打卡 + 等级 | 每日自动打卡、连签奖励、里程碑礼包（3~300 天）、补签卡、`cost(n)=40+2n` 满级 100（可开无限之路） |
| 🏆 37 项成就 | 速度 / 字数 / 每分钟正确率 / 总正确率，解锁后手动领取奖励 |
| 🚀 打字竞速挑战 | 内置 7 篇范文 + AI 定制生成，逐字对比精确正确率，百万级结算分 + 彩带庆祝 |
| 🤖 AI 范文生成 | OpenAI 兼容 API / 本地 Ollama / 自定义端点（Lv.45 解锁，训练券可提前体验） |
| 🎨 主题插件 | 内置浅色 / 深色 / 「明日方舟：终末地 · 梨诺」偶像舞台星空紫，支持 .zip 导入 |
| 🛡️ 隐私 | 只产生计数，**绝不记录/落盘任何字符内容**；数据全部在本地 |

## 🚀 快速开始

### 方式一：直接运行 exe（推荐）

从 [Releases](../../releases) 下载 `TypingTracker.exe`，双击运行即可。

- 数据目录默认 `%APPDATA%\TypingTracker\`（可用 `--data-dir` 指定）
- 单实例：重复启动会提示已在运行
- 关闭窗口 = 最小化到系统托盘，后台继续统计；托盘菜单可退出

### 方式二：源码运行（Windows / Python 3.10+）

```powershell
# 本地依赖目录（.deps，无需污染系统环境）
python scripts/fetch_deps.py
python main.py

# 或使用 venv / 系统环境
python -m pip install -r requirements.txt
python main.py
```

### 构建 exe

```powershell
powershell -File scripts\build.ps1   # 产物：dist\TypingTracker.exe
```

## 📖 使用手册

### 1. 主界面（今日概览）

- **状态行**：`🟢 统计中` = 键盘钩子正常；显示本次运行捕获的按键事件数；
  TSF 精确计数启用时显示"TSF 中文精确计数已启用"
- **等级区**：等级徽章、称号、渐变进度条（扫光动画）、连签天数
- **Hero 卡**：今日有效字数 / 平均速度（tw/分）/ 正确率（悬停看口径说明）
- **指标 chips**：今日输入、删除、改写率（删除÷输入）、tw、预测汉字/分、
  预测字母/分、活跃分钟、等级经验
- **终身汇总条**：累计输入 / 有效 / tw / 活跃分钟（只有总量，无平均速度与正确率）
- **今日逐分钟 tw 曲线**：实时更新

### 2. 统计口径（重要，请先读）

- **tw 统一单位**：1 字母 = 1tw，1 汉字 = 2tw（单位名可在设置中自定义）
- **今日正确率** = 有效字数 ÷ 输入字数（删除按键计入失误）；**按日独立，不并入终身**
- **平均速度** = 当日 tw ÷ 有输入的分钟数；**按日独立，不并入终身**
- **终身总计**只有总量类指标（输入/删除/有效/tw/活跃分钟）
- **中文输入**：组字中的按键不计，按上屏字符计；组字内退格/Esc 取消不误计
- 组合键（Ctrl/Alt/Win）不统计；被排除的程序完全不统计

### 3. 报表页

- **趋势分析**：近 7/30/90 天，速度 / 正确率 / 有效字数三线，可切换 tw/汉字/字母视角
- **打卡日历**：年度热力图，颜色深浅 = 当日 tw 量
- **时段分布**：近 7 天 24 小时 tw 柱状图
- **周月报**：本周/上周/本月/上月四卡 + 环比

### 4. 打卡页

- 每天首次启动自动打卡（连签递增，基础 20 exp + 连签加成，上限 150 天封顶）
- **里程碑礼包**：连签 3/7/14/30/60/100/200/300 天（经验 / 补签卡 / 加成卡 / 称号）
- **补签卡**：可补签昨天恢复连签（只允许补昨天）
- **经验加成卡**：30 分钟 ×2 打字经验（生效中不缩短剩余时间）

### 5. 成就页

- 37 项成就分四类：平均速度（近 7 日 × 活跃≥30 分钟）、累计字数、
  每分钟正确率（单分钟 ≥30 字样本）、总正确率（终身）
- 解锁后**手动领取**奖励（经验 / 补签卡 / 加成卡 / 称号），红点提示待领取

### 6. 竞速挑战页

- 选范文 → 开始挑战 → 对照输入（逐字高亮：绿=对、红=错）→ 打完自动结算
- **挑战中禁止粘贴**（防刷分）；挑战输入会计入今日统计
- **结算分** = (速度tw/分×0.6 + 正确字数×0.1 + 正确率%×0.5) × 10000 × 完成系数
  （60tw/分全对 ≈ 96 万分）；≥100 万金色彩带、≥200 万多彩狂欢
- 挑战经验：基础分 ×1（每日上限 200，按应用日）
- **AI 定制训练**：Lv.45 解锁（速度跃升奖励可得训练券提前体验）；
  支持 OpenAI 兼容（DeepSeek/智谱等）/ Ollama 本地，生成的范文持久化入库

### 7. 个人中心

- 头像（emoji 或上传图片圆形裁剪）、昵称、签名（设置中修改）
- 等级徽章、称号收藏（点击佩戴，主界面同步显示）
- 终身统计、道具库存（补签卡/加成卡/训练券/称号）、成就进度

### 8. 设置（右下角悬浮齿轮 / 托盘菜单）

| 设置项 | 说明 |
|--------|------|
| 昵称 / 签名 / 头像 | 个人中心展示 |
| 单位名称 | 默认 tw（1 汉字=2tw）；**建议保留 tw**，改为"字"会与预测汉字/分相差 2 倍 |
| 新的一天从几点开始 | 日切起点，默认凌晨 4 点（改后即时生效） |
| 无限等级之路 | 100 级后继续按公式累加 |
| 排除统计的程序 | 每行一个 exe 名，这些程序的打字完全不统计 |
| AI 配置 | 后端 / Base URL / API Key / 模型 / 测试连接 |
| 主题插件 | 切换 / 导入 .zip / 删除用户主题（取消对话框会还原预览） |
| 导出数据备份 | daily_stats.csv + data.json（API Key 已脱敏） |

### 9. 托盘

- 左键单击托盘图标：显示主界面
- 右键菜单：显示主界面 / 今日速览 / 设置 / 退出

## 📁 项目结构

```
main.py                    入口（单实例锁 / 钩子 / 托盘 / 主窗口）
app/
├── core/                  核心：键盘钩子（ImeCommitTracker）、TSF 精确计数、
│                          统计引擎、tw 换算、挑战评分
├── services/              业务：打卡 / 成就 / 挑战 / 鼓励 / 经验 / 道具 / AI / 导出
├── storage/               SQLite：schema + 迁移 + Repository
├── theme/                 主题系统（manifest / qss / charts）
└── ui/                    界面：主窗口、Dashboard、5 个页面、动效组件、调色板
config/                    数值配置（balance.json / achievements.json）
scripts/                   自检 / 诊断 / 构建 / 演示数据
```

## ⚠️ 说明

- 仅支持 Windows（键盘钩子 + TSF 依赖 Win32 API）
- 纯本地运行：AI 范文生成是唯一的联网功能（仅在你配置并使用时）
- 隐私：应用只统计计数，**不记录任何输入内容**
