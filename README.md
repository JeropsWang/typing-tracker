# 打字管家（TypingTracker）0.9.1

Windows 本地打字统计与练习应用，使用 Python、PySide6、pyqtgraph 和 SQLite。
本版为面向 [JeropsWang/typing-tracker](https://github.com/JeropsWang/typing-tracker) 的后续贡献版本。

## 本版改进

- 萨莉安娜界面：夜色插画、奶油纸张、艺术字和错位装饰，底部六项导航。
- 主窗口固定 1440×1024，设置窗口固定 820×640，关闭最大化；长范文与表单内部滚动。
- AI 范文表单独立封装，修复展开裁切、生成状态冲突和失败提示被刷新覆盖。
- 修复 AI 只返回思考而无正文的问题，新增思考开关、高消耗提示、每次请求的 token 用量与开发者测试彩蛋。
- 默认使用 Sariana 头像，提供默认、Q 版、正脸、侧脸、贝尔塔五款，支持上传本地图片。
- 个人练习榜按同一范文比较历史成绩，显示分数、速度、正确率和耗时。
- 独立英语入口：四级、六级、考研词库，中文释义到单词拼写，错词复习和 AI 英文语句跟打。
- Sariana 眨眼与手绘 SVG 发丝轻摆；原插画保持静止。动态效果可统一关闭，练习、隐藏和最小化时暂停。
- 修复同日重启覆盖统计、重复累计分钟与经验，以及 AI 工作线程跨线程访问 SQLite。

## 运行

仅支持 Windows。发布包中的 `TypingTracker.exe` 可直接运行。

源码运行需要 Python 3.10+：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

原有本地依赖方式仍可使用：

```powershell
python scripts/fetch_deps.py
python main.py
```

数据默认保存在 `%APPDATA%\TypingTracker\`，支持 `--data-dir` 指定目录。
关闭窗口会驻留托盘并继续统计，退出应用请使用托盘菜单。重复启动会提示单实例已在运行。

## 使用

| 入口 | 功能 |
| --- | --- |
| 今日 | 当日有效字数、活跃分钟、速度、估算正确率与逐分钟曲线 |
| 训练 | 内置与 AI 范文跟打、逐字对照、结算和同篇个人练习榜 |
| 英语 | 单词拼写、提示与答案、待复习词、AI 英文语句跟打 |
| 统计 | 近 7/30/90 日趋势、年度热力图、24 小时时段分布与周月对比 |
| 成长 | 打卡、补签、道具、37 项成就、称号和个人资料 |
| 设置 | 个人资料、统计规则、应用排除、AI 配置、外观、数据备份 |

### 统计与奖励

- `tw` 为统一计数单位：汉字 2tw，字母 1tw。组合键和被排除的应用不统计。
- 中文按上屏字符计数；组字内退格和取消不计为删除，TSF 支持的输入框使用精确上屏计数。
- 当日估算正确率为有效字数÷输入字数，平均速度为当日 tw÷有输入的分钟数；终身统计仅累计总量。
- 范文跟打按参考文本逐字计算正确率，练习中禁止粘贴，输入会计入今日统计。
- 挑战计分公式沿用原项目：`(速度×0.6 + 正确字数×0.1 + 正确率百分数×0.5) × 10000 × 完成系数`。
- 应用日默认凌晨 4 点切换；打卡、等级、经验、成就与道具规则沿用现有配置。

### 英语训练

内置词库来自 [ECDICT](https://github.com/skywind3000/ECDICT)，按锁定版本的考试标签整理：四级 3846 词，六级含四级基础词共 5802 词，考研 4801 词。
这些是考试参考词库，不表示官方最新完整大纲。来源版本、数量与文件哈希见 `config/vocabulary/manifest.json`，保留 `LICENSE-ECDICT.txt`。

选择词库后，每轮根据中文释义输入单词。使用提示或查看答案会记为辅助作答，进入待复习；再次独立答对后移出待复习。
AI 语句使用当前词库的目标词生成英文句子，成功校验后保存，可从历史材料再次跟打。
英语学习结果独立保存，本版不额外发放英语练习经验。

### AI 与隐私

AI 默认关闭，支持 OpenAI 兼容接口、自定义端点及本地 Ollama。配置模型后可测试连接。
思考模式默认关闭，已识别的接口自动适配开关，自定义代理可选择协议；无法关闭思考的模型会提示更换模型或开启思考。
开启思考可能消耗极高的 token；输出预算提高至 8,192，思考是否计入该预算由接口决定。范文、英语造句与连接测试显示接口返回的输入、输出、思考和总 token，缺失项显示「接口未返回」，思考用量不重复计入总计。
Lv.45 解锁 AI 生成，提前体验需训练券；英语与范文生成共用此规则。
开发者彩蛋可临时解锁本次运行的 AI 测试，不修改等级、经验或训练券，重启恢复；请求仍产生接口费用。
联网仅发生在主动测试连接或生成内容时，请求发送主题、目标词及生成指令。

后台键盘统计不保存实际敲击内容。练习成绩、错词进度、AI 生成材料、个人设置和上传头像保存在本机。
数据备份包含英语记录，API Key 在导出时脱敏。

### 外观与动效

唯一内置主题为「萨莉安娜」，旧深色或浅色设置会自动回退到它；第三方主题仍可导入、预览和删除，开发方式见 [THEMES.md](THEMES.md)。
设置 → 外观 → 动态效果，可统一关闭角色、星空、导航和作答动效。
角色发丝采用独立 SVG 笔触层，整束头发和原插画不做位图形变。

## 验证与构建

```powershell
.venv\Scripts\python.exe -B -m unittest discover -s scripts -p 'test_*.py' -v
.venv\Scripts\python.exe -B scripts/selftest.py
.venv\Scripts\python.exe -B scripts/preview_ui.py --interactive
powershell -File scripts\build.ps1
```

预览使用隔离数据库，不启用全局键盘钩子。构建输出为 `dist/TypingTracker.exe`。
AI 自动化测试使用模拟响应，真实模型效果取决于所配置的服务。

Windows Release 生成安装 EXE、免安装 ZIP、源码提交清单和 SHA-256 校验文件。安装版支持升级，卸载保留本机记录。
发布 Release 后，`Windows release assets` 工作流自动构建并上传附件；旧版本缺少附件时，在 Actions 手动运行并填写对应标签（如 `v0.9.0` 或 `v0.9.1`）。标签中的源码版本必须一致，标签应指向该版本提交；安装包不进入 Git。
本地构建先安装 `requirements-release.txt` 和 Inno Setup 6，再运行 `python scripts/build_release.py --help` 查看参数。历史版本使用独立的干净源码目录，构建工具与应用源码分开读取。

## 代码边界

```text
app/core/          键盘统计、TSF、计数与计分规则
app/services/      打卡、挑战、成就、AI、设置、导出等业务
app/storage/       公共 SQLite 仓储和迁移
app/english/       词库、拼写会话、学习服务与独立存储
app/ui/english/    英语页面和拆分的训练组件
app/ui/widgets/    导航、表单、头像、排行榜、纸张与动效组件
app/ui/assets/     运行必需的插画、头像、SVG 与图标
config/            数值配置和内置词库
scripts/           构建、导入、隔离预览与回归测试
```

计划、预览与交付过程记录保存在 `.local/`，不进入 Git；依赖、缓存、数据库和构建产物同样忽略。
项目沿用 MIT 许可，完整版本记录见 [CHANGELOG.md](CHANGELOG.md)。
